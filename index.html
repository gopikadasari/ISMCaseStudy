What LUN 3 holds

Transaction ledger

Every row is sealed with an HMAC-SHA-256 tag when it is written. Integrity alerts compare the tag again.

Audit trail

With tamper-evident audit on, each entry stores the SHA-256 hash of the one before it, so deleting or editing a line breaks the chain.

SafeTrust Bank is fictional and every customer, account and transaction here is sample data. Based on the 21CSE359T Information Storage and Management case study, SRM IST. Uses AES-256-GCM, HMAC-SHA-256, SHA-256 and TOTP through the browser's Web Crypto API.
